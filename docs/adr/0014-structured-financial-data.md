# ADR-0014: 재무 수치는 DART 구조화 재무 API를 우선한다

- 상태: 채택
- 날짜: 2026-09-04

## 맥락

정기보고서 원문 표에서도 재무 수치를 읽을 수 있지만 회사별 표 구조와 병합 셀이 다르다. DART는 XBRL 기반 전체 재무제표 API를 별도로 제공한다. 자기소개서 분석에는 정확한 핵심 추세가 필요하며 회계 분석 서비스 수준의 모든 계정은 필요하지 않다.

## 비교

| 후보 | 정확성·일관성 | 구현비용 | 한계 | 평가 |
|---|---|---|---|---|
| 원문 HTML/XML 표 파싱 | 원문 그대로 | 높음 | 회사별 표 구조, 단위·병합 셀 처리 | 보조 근거 |
| `fnlttSinglAcntAll` | XBRL 계정 ID와 기간 필드 | 중간 | IFRS 대상 회사·공시 범위 제한 | 채택 |
| 주요계정 API | 단순한 응답 | 낮음 | 필요한 계정 누락 가능 | 보류 |
| 외부 금융 데이터 API | 정규화 품질 가능 | 비용·연동 추가 | 별도 라이선스와 출처 | 제외 |

## 결정

`fnlttSinglAcntAll` 연결재무제표(CFS)를 우선 사용하고 결과가 없으면 개별재무제표(OFS)를 사용한다. 재무상태표는 `thstrm_amount`, 분기·반기 손익은 누적값인 `thstrm_add_amount`를 사용한다. 비교값은 사업보고서에서는 전기 금액, 분기·반기에서는 전기 누적금액을 사용한다.

핵심 지표는 자산, 부채, 자본, 매출, 영업이익, 당기순이익으로 제한한다. 계정 ID를 우선 매칭하고 회사별 확장 계정은 검증된 계정명 별칭으로 보완한다. 모든 값에는 사업연도, 보고서 코드, 연결/개별 구분, 통화와 접수번호를 보존한다.

## 감수하는 단점과 재검토

계정명이 회사별로 다르거나 XBRL 대상이 아니면 일부 지표가 비어 있을 수 있다. 주요 기업 평가에서 핵심 지표 누락률이 10%를 넘으면 계정 별칭을 보강하거나 주요계정 API와 원문 표를 함께 사용한다.
