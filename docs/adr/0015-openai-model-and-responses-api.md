# ADR-0015: GPT-5.4 mini와 Responses API의 구조화 출력을 사용한다

- 상태: 채택
- 날짜: 2026-09-04

## 문제와 제약

Phase 2는 채용공고와 DART 근거를 연결해 예측 가능한 JSON을 생성해야 한다. 초기 서비스이므로 한국어 품질을 유지하면서 호출비를 작게 제한해야 하며, 모델의 자유 형식 문장을 그대로 신뢰해서는 안 된다.

## 판단 기준

한국어 분석 품질, 구조화 출력 지원, 입력·출력 단가, 장문 문맥, SDK 유지보수성, 모델 교체 용이성을 기준으로 본다.

## 비교

| 후보 | 장점 | 단점 | 판단 |
|---|---|---|---|
| GPT-5.4 mini | Structured Outputs와 긴 문맥 지원, 입력 $0.75/M·출력 $4.50/M 토큰 | 상위 모델보다 복합 추론 여유가 작음 | 채택 |
| GPT-5.6 Terra | 더 높은 범용 추론 성능 | 입력 $2/M·출력 $12/M 토큰으로 MVP 비용 증가 | 보류 |
| GPT-5.6 Sol | 복잡한 고난도 분석에 적합 | 이 기능에는 비용과 지연이 과함 | 제외 |
| 로컬 오픈소스 모델 | 호출비와 데이터 통제 가능 | GPU 운영비·배포 복잡도·한국어 품질 검증 부담 | 제외 |

Chat Completions와 Responses API 중에서는 신규 기능 중심이며 Pydantic 스키마 파싱을 제공하는 Responses API를 선택한다. JSON mode보다 스키마 준수를 보장하는 Structured Outputs를 선택한다.

## 결정

기본 모델은 `gpt-5.4-mini`로 하고 `OPENAI_MODEL`로 교체 가능하게 한다. Python SDK의 `responses.parse`와 Pydantic 스키마를 사용한다. 출력은 3,000토큰으로 제한하고, 길이로 구조화 파싱이 실패한 경우 더 짧은 응답을 1회 재시도한다.

## 감수하는 단점과 재검토

연결 품질 평가에서 반복적으로 낮은 점수가 나오면 고성능 모델과 동일 평가셋을 비교한다. 사실성 문제가 생기면 모델을 올리기 전에 근거 선별과 인용 검증을 먼저 개선한다.
