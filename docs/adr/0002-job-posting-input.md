# ADR-0002: MVP 채용공고는 사용자 입력으로 받는다

- 상태: 채택
- 날짜: 2026-09-04

## 맥락

OpenDART는 공시 데이터 API이며 채용공고와 직무 정보를 제공하지 않는다. 여러 채용 사이트를 크롤링하면 각 사이트의 이용약관, robots 정책, 로그인, 동적 렌더링, 공고 삭제와 형식 차이를 동시에 해결해야 한다.

## 결정

MVP에서는 사용자가 채용공고 본문과 지원 직무를 직접 입력한다. URL은 출처 메타데이터로 선택 입력할 수 있지만 서버가 자동 수집하지 않는다.

## 판단 기준과 비교

| 후보 | 구현비용 | 데이터 안정성 | 약관·운영 위험 | 결정 |
|---|---:|---:|---:|---|
| 본문 직접 입력 | 낮음 | 사용자가 본 시점의 내용 보존 | 낮음 | 채택 |
| 범용 URL 크롤링 | 높음 | 사이트 변경·로그인에 취약 | 높음 | 보류 |
| 채용 플랫폼 공식 API | 중간 | API 품질에 따라 높음 | 낮음 | 접근권한 확보 후 검토 |
| 브라우저 확장 | 높음 | 현재 페이지 추출 가능 | 배포·권한 검토 필요 | 수요 확인 후 검토 |

## 결과

- 핵심 가치인 공시와 직무의 연결을 먼저 검증할 수 있다.
- 사용자가 입력한 채용공고의 저장 기간과 삭제 기능을 제공해야 한다.
- 자동 URL 가져오기는 사이트별 공식 API 또는 명시적으로 허용된 수집 방식이 확인된 후 어댑터 단위로 추가한다.

## 대안

- 범용 크롤러: 빠르게 보이지만 법적·운영·유지보수 위험이 커서 보류한다.
- 특정 채용 플랫폼 API: 접근 권한과 제품 수요가 확인되면 Phase 4에서 검토한다.

## 재검토 조건

직접 입력 이탈률이 높거나 특정 플랫폼의 공식 API 접근권한과 충분한 사용자 수요가 확인될 때 재검토한다.
