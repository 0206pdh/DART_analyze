# 제품 범위

## 문제

취업 준비자는 기업의 최근 사업 방향을 공시에서 찾아 채용 직무와 자기소개서에 연결하기 어렵다. 서비스는 공시를 대신 읽어주는 데서 끝나지 않고, 어떤 경험을 어떤 기업 과제와 연결할지 근거와 함께 안내한다.

## 핵심 사용자 흐름

1. 회사명을 검색해 정확한 법인을 선택한다.
2. 채용공고 본문을 붙여 넣고 지원 직무를 입력한다.
3. 최근 사업·반기·분기보고서와 주요 재무 변화를 불러온다.
4. 공고의 요구 역량과 공시의 전략·리스크·사업 변화를 연결한다.
5. 사용자의 경험을 추가로 입력받아 자기소개서 방향, 문항별 개요, 활용 근거를 만든다.
6. 사용자는 각 주장에 연결된 공시 출처를 열어 확인한다.

## MVP 결과물

- 기업 식별 정보와 최근 정기공시 목록
- 회사·직무·채용공고 요구사항 요약
- 최근 보고서 기반 핵심 사업 방향, 변화, 기회, 리스크
- `채용 요구사항 → 공시 근거 → 강조할 사용자 경험` 매핑
- 자기소개서 문항별 메시지와 STAR 초안 구조
- 각 기업 사실에 대한 보고서명, 접수일, 접수번호/원문 링크
- 정보 기준일과 “제안이며 회사의 채용 의도를 확정한 것이 아님” 안내

## MVP에서 하지 않는 것

- 모든 채용 사이트의 자동 크롤링
- DART에 없는 비공개 기업·채용 정보의 추정
- 근거 없는 기업 인재상 생성
- 완전 자동 제출 또는 합격 가능성 점수화
- 처음부터 벡터 데이터베이스, 이벤트 버스, 마이크로서비스 도입

## 성공 기준

- 회사명 검색 후 올바른 `corp_code` 선택이 가능하다.
- 선택한 회사의 최신 정기보고서가 정정본을 고려해 노출된다.
- 분석의 기업 관련 핵심 주장 대부분이 사용자가 열람 가능한 출처를 갖는다.
- 3개 이상의 실제 채용공고에서 요구 역량과 공시 근거의 연결이 사람이 보기에 유용하다.
- 한 번의 분석 실패가 재시도 가능하며 API 키나 사용자 입력이 로그에 노출되지 않는다.

## 핵심 리스크

| 리스크 | 먼저 확인할 것 |
|---|---|
| 보고서 원문 XML의 회사별 구조 차이 | 대표 기업 5곳의 사업/반기/분기 원문 파싱 스파이크 |
| 모델의 근거 없는 연결 | 인용 가능한 근거만 컨텍스트에 넣고 문장별 source id 강제 |
| 동명이인·유사 회사명 | 로컬 회사 인덱스에서 정식명, 종목코드, 시장 구분을 함께 표시 |
| 채용공고 이용약관·robots 제약 | MVP는 사용자 붙여넣기, URL 수집은 사이트별 검토 후 추가 |
| DART 호출 제한·장애 | 캐시, 동기화, 타임아웃, 제한 오류(020) 처리 |
