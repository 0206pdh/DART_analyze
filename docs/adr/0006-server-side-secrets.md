# ADR-0006: 외부 API 인증키는 서버 환경변수로 관리한다

- 상태: 채택
- 날짜: 2026-09-04

## 맥락

OpenDART 인증키는 모든 API 호출에 포함되는 비밀정보다. 정적 프런트에 넣으면 누구나 브라우저 개발자 도구에서 복사할 수 있고, 저장소에 커밋하면 이력에 남는다.

## 판단 기준과 비교

| 후보 | 보안 | 로컬 편의 | 운영 적합성 | 결정 |
|---|---|---|---|---|
| 소스/프런트 상수 | 매우 낮음 | 높음 | 부적합 | 금지 |
| 커밋하지 않는 `.env` | 보통 | 높음 | 단일 서버 외에는 한계 | 로컬 선택지 |
| 프로세스 환경변수 | 보통~높음 | 보통 | 대부분의 배포 플랫폼 지원 | 채택 |
| 클라우드 비밀관리 서비스 | 높음, 감사·회전 지원 | 낮음 | 공개 운영에 적합 | 배포 시 검토 |

## 결정

애플리케이션은 `DART_API_KEY` 환경변수에서만 키를 읽는다. 로컬에서는 프로젝트 루트의 `.env`를 명시적으로 로드하며, 이미 설정된 프로세스 환경변수를 덮어쓰지 않는다. 프런트는 자체 백엔드 API만 호출한다. `.env`는 `.gitignore`에 포함하며 로그와 오류 응답에 키를 출력하지 않는다.

## 감수하는 단점

- 개발자가 셸 또는 로컬 `.env`에 키를 직접 설정해야 한다.
- 환경변수만으로는 키 회전과 접근 감사 기능이 없다.

## 재검토 조건

첫 공개 배포 시 플랫폼의 비밀 저장소를 사용하고, 다중 환경 또는 팀 권한 분리가 필요하면 전용 비밀관리 서비스를 검토한다.
