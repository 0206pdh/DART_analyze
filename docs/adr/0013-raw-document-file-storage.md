# ADR-0013: 원문 ZIP은 DB가 아닌 파일시스템에 저장한다

- 상태: 채택
- 날짜: 2026-09-04

## 비교

| 후보 | 장점 | 단점 | 평가 |
|---|---|---|---|
| SQLite BLOB | 트랜잭션과 백업이 하나 | DB 파일 팽창, 읽기·백업 부담 | 제외 |
| 로컬 영구 볼륨 | 추가 서비스 비용 없음, 스트리밍·삭제 쉬움 | 단일 서버 종속 | 채택 |
| 객체 스토리지 | 내구성과 다중 서버 접근 | 별도 비용·설정 | 성장 후 후보 |
| 원문 미보관 | 저장비 없음 | 반복 DART 호출과 재현성 저하 | 제외 |

## 결정

`data/documents/{receipt_number}.zip`에 원문을 원자적으로 저장하고 SQLite에는 SHA-256, 크기, 상대경로를 저장한다. 접수번호는 14자리 숫자로 검증해 경로 조작을 차단한다.

## 재검토 조건

다중 서버 배포, 5GB 초과, 더 높은 내구성 요구 중 하나가 발생하면 S3 호환 객체 스토리지로 이전한다.
