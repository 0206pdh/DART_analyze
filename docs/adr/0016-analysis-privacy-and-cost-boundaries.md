# ADR-0016: 모델 전송량과 분석 저장 범위를 최소화한다

- 상태: 채택
- 날짜: 2026-09-04

## 문제와 제약

지원자 경험에는 개인정보가 포함될 수 있고 DART 원문 전체 전송은 비용과 잡음을 늘린다. 결과 재조회와 품질 추적에는 최소한의 기록이 필요하다.

## 판단 기준

개인정보 노출, 재현성, 저장비, 모델 비용, 구현 복잡도를 기준으로 본다.

## 비교

| 후보 | 장점 | 단점 | 판단 |
|---|---|---|---|
| 모든 입력·원문·결과 저장 | 완전한 재현과 디버깅 | 개인정보와 저장량이 큼 | 제외 |
| 아무것도 저장하지 않음 | 개인정보 최소화 | 결과 이력·품질 추적 불가 | 보류 |
| 결과·출처·입력 해시만 저장 | 입력 원문을 피하면서 이력 식별 가능 | 동일 입력의 완전 재생성 불가 | 채택 |

## 결정

모델에는 최대 20,000자의 공고, 10,000자의 경험, 최대 40,000자의 선별 공시 근거만 전달한다. OpenAI 응답 저장은 `store=false`로 요청한다. 로컬 DB에는 직무, 결과 JSON, 사용한 출처, 모델과 토큰 수, 입력 SHA-256만 저장하고 공고와 경험 원문은 저장하지 않는다.

모델 입력에서 발견되는 명령은 데이터로 취급하도록 개발자 지침에 명시하고, 도구 호출은 제공하지 않는다. 공개 배포 전에 인증·삭제 정책을 추가해야 한다.

## 감수하는 단점과 재검토

해시만으로 과거 입력을 복원할 수 없다. Phase 3에서 사용자가 명시적으로 저장을 선택하고 삭제할 수 있는 암호화 저장소를 별도 검토한다. 월 비용이 목표를 넘으면 근거 길이와 출력 토큰을 먼저 낮춘다.
